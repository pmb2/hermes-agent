# Changelog

Hermes Agent uses date-based version tags (`vYYYY.M.D`) with a community-standard [Keep a Changelog](https://keepachangelog.com/) format.

## What's in the Changelog

The changelog catalogs all user-facing changes across releases, organized into:

- **Added** — new features, models, integrations
- **Changed** — behavior changes, new defaults, deprecations
- **Fixed** — bug fixes and stability improvements
- **Removed** — feature removals and discontinued options

Internal refactors, CI-only changes, and chore commits are excluded — those live in git history.

## How to Use

- **Upgrading?** Check the latest release section for breaking changes and new defaults.
- **Tracking a feature?** Search the changelog for the version where it landed.
- **Reporting a bug?** Check the Fixed section to see if it's already resolved.

## View the Changelog

The full changelog is maintained at the repository root:

- **GitHub:** [CHANGELOG.md on GitHub](https://github.com/NousResearch/hermes-agent/blob/main/CHANGELOG.md)

For release announcements and upgrade notes, follow [`#hermes-dev`](https://github.com/NousResearch/hermes-agent/) on GitHub.
